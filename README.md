## 📁 Organization

Each laboratory has its own folder under `cpp/`.

A lab folder contains the source code and the Visual Studio files needed to open and build the application. Reports, diagrams and screenshots may also be included where available.

| File type | Purpose |
| --- | --- |
| `.cpp`, `.h`, `.hpp` | Source code and headers |
| `.sln` | Visual Studio solution |
| `.vcxproj` | C++ project and build configuration |
| `.vcxproj.filters` | File organization in Visual Studio |
| `README.md` | Lab-specific explanation and usage |
| `.pdf` | Report, when included |

Generated binaries, build directories and local IDE settings are excluded through `.gitignore`.

## ▶️ Running a Lab

### Requirements

- Windows
- Microsoft Visual Studio with the **Desktop development with C++** workload

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/Proggertopper/programming-labs.git
   ```

2. Open the folder of the laboratory you want to run.
3. Open its `.sln` file in Visual Studio.
4. Build the solution.
5. Run the application with **Ctrl + F5**.

If Visual Studio reports a missing toolset or Windows SDK, install the required component or retarget the project to an installed version.
